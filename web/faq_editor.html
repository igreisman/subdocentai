FAQ Editor

How to use the FAQ Editor

Purpose

Add new FAQ entries or edit existing ones. Changes are saved directly to the corpus — no scripts, no terminal, no coding needed.

Entry types

faq

faq_NNN — Main curated FAQ entries used by the docent AI. Edit and add to these most often.

der

der_NNN — AI-derived from dieselsubs.com. Use the FAQ Review tool to promote these.

pam

pam_NNN — AI-generated. May contain factual errors — review carefully.

fix

fix_NNN — AI-generated entries corrected by an expert reviewer.

Adding a new FAQ

1

Click + New FAQ in the toolbar.

2

Type the Title — phrase it as a question, e.g. How deep could a submarine dive?

3

Type the Answer text. Plain paragraphs work best.

4

Click Save. The entry is assigned the next faq_NNN ID automatically.

Editing an existing FAQ

1

Use the filter buttons and search box to find the entry.

2

Click it in the list to open the editor on the right.

3

Edit the Title and/or Answer text, then click Save changes.

4

Click Discard edits to undo all changes before saving.

Tips

  • Use the faq_ filter to see only the main curated entries.
  • The stats bar (top right) shows how many entries match the current filter.
  • If you navigate away with unsaved changes, the browser will warn you.
  • To promote a pam_, der_, or fix_ entry to faq_NNN, use the FAQ Review tool.
  • To see the public FAQ page (which replaced dieselsubs.com), visit faqs.html.
