# Project Costs Summary

As of March 25, 2026, this project is relatively inexpensive to operate in its current form. The main ongoing costs are hosting and domain renewals. Optional voice features may add usage-based costs. For a physical deployment on the Pampanito, the largest launch costs are likely to be hardware, connectivity setup, and staff time.

This version is intended for budgeting and approval discussions and leaves out implementation detail.

## 1. Cost Picture At A Glance

- The software itself is low-cost compared with most custom interactive systems.
- The main recurring cost is hosting.
- Domain renewal is a small annual cost.
- Voice input, if enabled, adds a variable usage-based cost.
- For on-site deployment, the main cost is not the software. It is the equipment, connectivity, and setup work needed to make the visitor experience reliable.

## 2. Recurring Costs

### Hosting

- Expected range: `7` to `25` dollars per month
- Lowest-cost pilot or demo use may be less
- A more reliable public deployment should budget in this range

### Domain Names

- Expected range: `25` to `50` dollars per year if both domains are retained

### Email Delivery

- If an existing email account is used, the incremental cost may be `0`
- If a dedicated account is preferred, expect a small monthly administrative cost

### Voice Transcription

- This is optional
- If enabled, it is a variable usage-based cost rather than a large fixed monthly bill
- For modest use, it should remain a relatively small operating expense

## 3. One-Time Launch Costs

### Local Host Machine

- If existing equipment is reused: `0`
- If a dedicated machine is purchased: roughly `500` to `1,500` dollars
- Practical planning range: `800` to `1,200` dollars

### Network And Connectivity Setup

- Expected range: `200` dollars to low thousands
- Final cost depends on how much equipment, cabling, installation, and testing are needed

This is the main launch uncertainty for an onboard deployment. Reliable visitor connectivity across the full experience path should be treated as a required launch cost.

### Visitor Devices

- If visitors use their own phones: `0` device cost to the project
- If the museum supplies devices: costs can rise quickly due to phones or tablets, charging, storage, mounts, and maintenance

### Setup And Testing Labor

- Staff and contractor time should be budgeted separately for installation, testing, launch preparation, and support

## 4. Budget Scenarios

### Scenario A: Public Information Site Or Pilot

- Monthly cost: `0` to `7` dollars
- Annual domain cost: `25` to `50` dollars

Best fit:

- Public informational site
- Internal demo
- Small pilot deployment

### Scenario B: Practical Public Production Deployment

- Monthly cost: about `10` to `40` dollars
- Annual domain cost: `25` to `50` dollars
- Includes hosting plus small optional service costs

Best fit:

- Stable public site
- Ongoing light operational use

### Scenario C: On-Site Pampanito Deployment

- Recurring software cost: near zero to very low if mostly local
- One-time hardware and setup cost: roughly `800` to `1,500` dollars for a host machine, plus network and installation costs
- Main cost driver: making the on-board visitor experience dependable in real conditions

## 5. Main Budget Risks

- The largest uncertainty for the Pampanito deployment is connectivity and installation, not the software subscription cost
- If future versions add more AI-generated voice or more advanced answer generation, recurring operating costs could rise
- If museum-owned visitor devices are added, capital and maintenance costs could exceed the software budget

## 6. Recommended Budget Framing

For approvals and planning, this project can be described simply as follows:

- The software baseline is low-cost
- Hosting is the main recurring expense
- Domains are a small annual expense
- Optional voice features add modest variable costs
- The main launch budget item for Pampanito is hardware, connectivity, and deployment labor

## 7. Recommended Planning Summary

- Public/cloud deployment: budget about `10` to `40` dollars per month plus domain renewals
- On-site deployment with reused equipment: very low software cost, mostly labor and setup
- On-site deployment with dedicated equipment: roughly `800` to `1,500` dollars one-time for a host machine, plus network and installation costs

## 8. Recommendation

Approve the project on the basis that:

- Ongoing software costs are modest
- The main launch cost is physical deployment readiness
- The most important pre-launch validation is real-world testing of the full visitor experience under operating conditions
